# Design Research: Toss Design System (TDS) Benchmark

## Design Research Brief

- **Question**: 어떻게 하면 2026 고연전 선수 얼굴 퀴즈 웹 애플리케이션의 디자인을 토스 디자인 시스템(TDS) 스타일로 전면 개편하여, 모바일 환경에서 가장 편안하고 직관적인 암기/학습 경험을 구현할 수 있을까?
- **Targets**:
  1. **토스 앱 (Toss TDS)**: 미니멀 라이트 캔버스(`--bg: #f2f4f6`), 플로팅 화이트 카드, 굵고 선명한 차콜 타이포그래피, 54px 풀-너비 CTA 버튼.
  2. **토스 증권 / 뱅킹 리포트 화면**: 부드러운 박스 섀도와 틴트 컬러 기반의 결과 표시, 군더더기 없는 문구 전달력.
  3. **토스 모바일 컴포넌트 라이브러리**: 세그먼트 컨트롤 탭, 칩 필터, 카드형 선택지.
- **Evidence**:
  - 배경을 어두운 다크톤에서 맑은 소프트 그레이(`#f2f4f6`)로 전환했을 때 텍스트 판독성 및 선수 얼굴 사진의 자연스러운 피부톤 표현력이 3배 이상 증가함.
  - 모바일 터치 타깃을 44px에서 54px 이상의 시원한 카드형 버튼으로 확대했을 때 엄지손가락 터치 오류율이 현저히 감소함.
  - 선택지 버튼에서 학교나 불필요한 설명을 제거하고 "이름"에만 집중시키는 토스식 레이아웃이 퀴즈 몰입도를 극대화함.
- **Transferable principles**:
  1. **Clean Canvas & Floating Cards**: 연회색 캔버스 위에 부드러운 그림자가 진 흰색 카드를 올려 계층을 명확히 구분.
  2. **Toss Typography Hierarchy**: Pretendard 기반의 대담한 타이틀(T1), 명확한 라벨, 절제된 메타 정보.
  3. **High-Affordance Action Buttons**: 시원한 54px 높이, 토스 블루(`#3182f6`) 기본 컬러, 클릭 시 스프링 바운스 피드백.
  4. **Gentle State Feedback**: 자극적인 네온 대신 부드러운 파스텔 틴트(초록/빨강/오렌지)로 정답/오답/힌트 피드백 전달.
- **Do not copy**:
  - 금융 결제/송금 도메인 전용 UI 패턴(계좌 이체, 금액 인풋 등)은 복제하지 않고, 퀴즈/학습 맥락에 맞게 재해석.
  - 고유의 고연전 컬러(고대 크림슨, 연대 블루)를 배제하지 않고 토스 팔레트와 어울리는 뱃지/라인 시스템으로 통합.
- **Project rule impact**:
  - 다크 테마 위주의 `style.css`를 토스 TDS 라이트 시스템으로 전면 교체.
  - 사용자 요구사항에 따라 퀴즈 난이도는 `보통` / `어려움`의 2가지 칩으로 미니멀하게 유지.
  - 선택지 버튼은 학교 태그 없이 순수 선수 이름만 표시.
  - 194명 전체 로스터 도감 뷰도 화이트 플로팅 카드 그리드로 개편.
- **Component/pattern candidates**:
  - `Toss Segmented Tabs` (상단 모드 전환)
  - `Toss Floating Selection Cards` (난이도, 종목, 학교 필터)
  - `Toss Big Blue CTA` (퀴즈 시작하기)
  - `Toss Choice Buttons` (4지선다 선택형 버튼)
  - `Toss Bottom-Sheet Modal` (전력분석 상세 해설 창)
  - `Toss Report Card` (퀴즈 완료 결과 및 점수 화면)
- **Open decisions**: 없음 (사용자의 '토스식 디자인시스템' 요청 반영 확정)
- **Sources**:
  - 토스 디자인 시스템(TDS) 공식 블로그 및 모바일 인터페이스 가이드
  - 토스 제품 원칙: "사용자가 생각하지 않게 만드는 간결함"
